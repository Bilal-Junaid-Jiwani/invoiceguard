v0.1.0

latest 2026-09-30

Initial release. The full loop works: contract → deposit → invoice → automatic escalation.

  • CLI: init, dashboard, check-due, client add, project create, invoice create
  • Stripe deposit payment links per project, test-mode friendly
  • Late-fee contract with client acknowledgment checkbox before deposit
  • Automatic 3-stage dunning: day-1 polite nudge → day-7 firm reminder → day-15 formal notice quoting the signed clause
  • Local-first: SQLite database, single YAML config, bring-your-own SMTP
  • Docker Compose setup for containerized runs
  • Fully editable email templates and late-fee terms in config
