Quickstart

Up and running in minutes.

Install, initialize, set your Stripe key, add a client, create a project, create an invoice — then let a daily cron run the escalation.

terminal
# install (InvoiceGuard isn't on PyPI — install straight from the repo)
pip install git+https://github.com/Bilal-Junaid-Jiwani/invoiceguard.git

# one-time setup: SQLite database + single YAML config
invoiceguard init

# set your Stripe TEST key first — invoice create needs it
export INVOICEGUARD_STRIPE_SECRET_KEY="sk_test_..."

# add a client, create a project (deposit link + late-fee contract)
invoiceguard client add
invoiceguard project create

# create the final invoice with a due date
invoiceguard invoice create

# check what's overdue and send day-1 / day-7 / day-15 escalations
invoiceguard check-due

# run it every morning via cron:
0 9 * * * invoiceguard check-due

Prefer a UI? invoiceguard dashboard serves the local dashboard on your machine.
